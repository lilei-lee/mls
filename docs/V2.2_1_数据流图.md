# V2.2 #1 核心数据流图

## 1. LA 录入房源

```
Flutter 录入页
  │ Step A: POST /listings
  │   body: identity + physical(6) + marketing + sale_points
  │         + public_remarks + agent_remarks + showing_instructions
  │         + objective_features + decoration
  v
MLS create_listing()
  │ 1. 调辞典 POST /v1/properties/identify → property_code
  │ 2. 调辞典 POST /v1/properties/{code}/claims
  │    body: physical(6) + objective_features + decoration
  │ 3. 写 MLS listings 集合(仅营销字段 + property_code)
  v
MLS listings 集合
  │ { house_code, district, community, property_code,
  │   layout, orientation, price_wan, bonus_yuan,
  │   sale_points, public_remarks, agent_remarks,
  │   showing_instructions, photos, ... }
  │
  │ Step B: POST /listings/{id}/sync-physical
  │   body: objective_features + decoration
  v
辞典 claims 集合 (always-accept)
  │ attribute_claims += [{ field, value, agent_id, claimed_at }]
  │ 比对引擎: first_claim → consistent → differs (生 discrepancy)
  v
完成
```

## 2. LA 编辑房源

```
Flutter 编辑页(预填 my_last_claim + original)
  │ Step A: PATCH /listings/{id}
  │   body: orientation, price_wan, bonus_yuan, photos,
  │         sale_points, public_remarks, agent_remarks,
  │         showing_instructions
  v
MLS update_listing()
  │ 更新 MLS listings 文档中的营销字段
  │
  │ Step B: POST /listings/{id}/sync-physical
  │   body: physical(6) + objective_features + decoration
  │   若 _BuildSyncBanner 黄条触发 → 一键同步权威值
  v
辞典 claims 集合
  │ always-accept + 比对引擎
  │ force=false(默认) → 无 409(Day 26 spec 修订)
  v
完成
```

## 3. BA 共享库筛选

```
Flutter 共享库 FilterSheet
  │ GET /listings/shared
  │   params: sale_points, objective_features, decoration,
  │          heating_type, bld_year_min, bld_year_max
  v
MLS list_shared_listings()
  │ Step A: MongoDB $all(sale_points) + owner_id != viewer
  │ Step B: 辞典 batch_get_properties(codes)
  │          + 辞典 communities.find_by_name(names)
  v         (直连 property_dict MongoDB)
  │ Step C: _passes_dict_filters()
  │   objective_features AND → attribute_claims_latest
  │   decoration EQ → attribute_claims_latest
  │   heating_type EQ → community doc
  │   bld_year range → community.bld_year_start
  v
返过滤后 listing 列表 + total
  │ _format_listing_anonymous_lite(doc)
  │ _enrich_physical_fields(r, props_map)
  v
Flutter 共享库卡片(5 行)
```

## 4. BA 详情页加载

```
Flutter 详情页
  │ GET /listings/{id}
  v
MLS get_listing_by_id(viewer_id)
  │ _format_listing_full(doc)
  │ _enrich_from_dictionary(result, doc, viewer_id)
  │   └ 辞典 GET /v1/properties/{code}
  │     → authoritative_attrs + attribute_claims_latest
  │     → my_last_claim(LA 视角)
  │ _enrich_community_from_dict(result, doc)
  │   └ property_dict.communities.find_one({name})
  │     → 18 字段 → community_features
  │ is_collaboration_unlocked(viewer_id, listing_id)?
  │   ├ YES → 返全字段(agent_remarks + showing_instructions + phone)
  │   └ NO  → 隐藏 agent_remarks/showing_instructions/phone
  v
Flutter 详情页 6 section
  ② 基础信息 + 格局 chips + 社区迷你卡
  ③ 卖点标签
  ④ 房源描述(public_remarks)
  ⑤ 协作信息(LA + 奖金)
  ⑥ 权限分层(unlocked? 同行私话+看房安排 : 🔒锁形)
```

## 5. BA 申请协作通过 → 详情页解锁

```
BA 发起申请
  │ POST /showing-requests
  v
LA 审批通过 → showing_request.status = approved
  │
  v
BA 打开详情页
  │ GET /listings/{id}(viewer=BA)
  v
is_collaboration_unlocked(BA_id, listing_id)
  │ db.showing_requests.findOne({
  │   listing_id, buyer_agent_id: BA_id,
  │   status: {$in: [approved, auto_approved, in_progress, completed]}
  │ })
  │ → 找到 → 返 True
  v
返全字段: agent_remarks + showing_instructions + owner_agent_phone
  │
Flutter 详情页 ⑥ section
  │ agent_remarks 全文 + 🔓 同行私话标识
  │ showing_instructions 全文 + 📋 看房安排标识
  │ LA 联系电话
```
