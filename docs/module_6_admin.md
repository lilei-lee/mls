# 一、模块概述

Web管理后台是MLS系统的运营管理端，仅磊和运营团队使用，经纪人不可访问。后台承担平台运营的全部管理职能：经纪人管理、房源审核、小区库维护、争议处理、数据看板。

> *技术选型：独立Web端应用，与小程序共用同一套后端API。浏览器访问，无需安装。*

# 二、权限与角色

## 2.1 角色设计

| **角色**   | **权限范围**                               | **种子期人员**         |
|------------|--------------------------------------------|------------------------|
| 超级管理员 | 全部权限，包括角色分配、系统配置、仲裁裁决 | 磊                     |
| 运营人员   | 经纪人管理、房源审核、小区库维护、数据查看 | 种子期不需要，后期扩展 |
| 仲裁员     | 争议处理、裁决出具                         | 种子期由超级管理员兼任 |

## 2.2 登录方式

账号密码登录。种子期只有一个管理员账号。后期支持多账号 + 角色分配。

# 四、经纪人管理

## 4.1 经纪人列表

展示所有注册经纪人（包括门店老板），支持按姓名、门店、状态、注册时间、账号类型筛选和搜索。

| **列表字段**  | **说明**                         |
|---------------|----------------------------------|
| 姓名 + 手机号 | 基本身份信息                     |
| 账号类型      | 门店老板 / 经纪人 / 独立经纪人   |
| 门店名称      | 所属门店                         |
| 注册时间      | 加入平台的时间                   |
| 联卖审核状态  | 待审核 / 已通过 / 已拒绝         |
| 状态          | 正常 / 暂停 / 已踢出 / **已离职**（V3新增）|
| 在库房源数    | 当前拥有的房源数量               |
| 成交数        | 累计通过平台成交的数量           |
| 违规记录      | 轻微/严重违规次数                |
| 最后活跃时间  | 最后一次登录或操作的时间         |

## 4.2 经纪人详情

点击经纪人进入详情页，展示：基本信息（门店老板额外显示门店管理信息和名下经纪人列表）、名下所有房源列表、所有带客记录、所有成交记录、违规和处罚历史、完整操作日志。

## 4.3 管理操作

| **操作**           | **说明**                                                         |
|--------------------|------------------------------------------------------------------|
| 联卖审核           | 审核通过/拒绝经纪人的联卖权限申请                                |
| 编辑信息           | 修改经纪人基本信息（如门店变更）                                 |
| 手动暂停           | 不经过仲裁流程，直接暂停经纪人使用权（紧急情况使用）             |
| 解除暂停           | 恢复被暂停经纪人的使用权                                         |
| 永久踢出           | 不经过仲裁流程，直接踢出（极端情况使用）                         |
| 标记离职（V3新增） | 标记经纪人已离职，其名下房源自动锁定，通知门店老板分配接手人     |
| 房源重新分配（V3新增）| 将离职/被移除经纪人的锁定房源指定新的归属经纪人                |

> *手动暂停和踢出操作记入audit_log，需填写原因。联卖审核结果通知经纪人（服务号+小程序）。*

# 五、房源管理

## 5.1 房源列表

展示所有房源，支持按小区名、MLS编号、状态、区域、经纪人筛选和搜索。

| **列表字段**         | **说明**                                                                  |
|----------------------|---------------------------------------------------------------------------|
| MLS编号              | 唯一标识                                                                  |
| 小区名 + 户型 + 面积 | 房源基本信息                                                              |
| 总价                 | 挂牌价                                                                    |
| 状态                 | 即将上市/在售/定金已付/成交进行中/暂停挂牌/已售/撤牌/待确认/已下架/**锁定**（V3新增）|
| 归属经纪人           | Listing Agent姓名 + 门店                                                  |
| 发布时间             | 录入时间                                                                  |
| DOM                  | 在市场天数（暂停期间不计算）                                              |
| 是否有委托           | 已验证/未验证                                                             |
| 委托到期日           | 有委托时展示，临近到期（14天内）标红                                      |

## 5.2 房源详情

后台房源详情展示经纪人端的所有信息，外加：个人备注（后台可见）、独家委托协议原件、全部操作日志、所有带客申请和带看记录、价格变动完整历史、DOM暂停/恢复历史、归属移交历史（V3新增）。

## 5.3 审核与管理操作

| **操作**     | **说明**                                   |
|--------------|--------------------------------------------|
| 照片审核     | 巡检照片质量，不合规的标记并通知经纪人     |
| 信息审核     | 检查房源信息完整性和准确性                 |
| 手动下架     | 不合规房源强制下架，需填写原因             |
| 恢复上架     | 经纪人完善后，后台审核通过可恢复上架       |
| 归属变更     | 审核独家委托协议，执行房源归属转移         |
| 手动状态变更 | 紧急情况下手动修改房源状态                 |
| 房源移交分配（V3新增）| 将锁定房源指定新的归属经纪人       |
| **定金凭证审核**（V4新增）| **巡检定金已付房源的凭证真实性，虚假凭证按严重违规处理** |
| **定金异常审查**（V5新增）| **展示30天内反复标记定金/回退超过2次的房源列表，供后台核实是否存在恶意操作** |
| **归属变更二次校验**（V4新增）| **归属变更审核通过后执行前，系统自动二次校验房源状态。后台可查看校验结果和中止原因** |
| **代完成成交确认**（V5更新，V7补充）| **任何一方在成交确认流程中被暂停/踢出导致流程卡住，另一方申请后台代为确认。**自促成交（LA=BA）中被暂停/踢出时无另一方，后台可直接代为确认无需申请触发。**后台核实后执行。（详见模块五V9 §3.4b）** |

# 六、小区库管理

## 6.1 小区列表

展示所有小区，支持按标准名、别名、区域搜索。显示每个小区下的房源数量和关注人数。

## 6.2 小区编辑

编辑小区全部字段。

## 6.3 小区合并

将A合并入B：A下所有房源归入B，A名称添加为B别名，关注A的经纪人自动转为关注B（**如果该经纪人已关注B则去重，不产生重复关注记录**），A从库中删除。操作前预览影响范围。操作记入audit_log。

## 6.4 新增字段

后台可随时为小区库新增字段模板，不需要改代码。动态字段模式（key-value结构）。

# 七、争议处理

## 7.1 争议列表

展示所有争议举报，支持按状态筛选：待受理、审理中、已裁决。

## 7.2 争议详情与审理

展示：举报方和被举报方的争议描述和证据、系统自动调取的完整交易留痕时间线。

## 7.3 仲裁操作

| **操作**     | **说明**                                                        |
|--------------|-----------------------------------------------------------------|
| 受理         | 确认受理争议，通知被举报方提交答辩                              |
| 要求补充材料 | 向任一方或双方发出补充材料通知                                  |
| 出具裁决     | 填写：事实认定、违规判定、处罚决定                              |
| 执行处罚     | 裁决出具后，确认执行处罚                                        |
| 驳回举报     | 争议不成立，填写驳回理由                                        |

## 7.4 时间线视图

以时间线形式展示争议涉及的完整操作链。每个节点可展开查看详情和原始数据。从audit_log中提取数据，自动关联所有相关记录。

## 7.5 奖金结算人工介入（V3新增）

后台展示所有标记为「需人工介入」的结算单列表。后台可查看关联交易的完整留痕数据，主动联系相关方（包括已被踢出的经纪人）跟进结算状态，手动更新结算单为「已结清」或「确认无法结算」。

## 7.6 成交确认管理（V6新增）

后台提供成交确认的管理视图：

| **视图** | **内容** |
|---|---|
| 待确认成交列表 | 所有待LA确认的成交记录，标注已等待天数，临近超时（6天+）标红 |
| 价格不一致记录 | 展示BA填写价格和LA填写价格不一致被系统自动驳回的记录，供后台关注 |
| 被撤回的成交 | 展示BA撤回的成交确认记录，含撤回原因和时间 |
| 超时自动生效记录 | 展示7天超时自动生效的成交记录，供后台核实 |
| 代确认记录 | 展示后台代为确认的成交记录，含代确认原因和操作人 |
| **驳回超限冻结记录**（V7新增） | **展示因成交确认驳回超过2次被系统冻结的BA-房源对，供后台关注是否需要主动介入调解** |
| **自促成交待代确认**（V7新增） | **展示LA=BA被暂停/踢出导致卡住的自促成交记录。此类记录无"另一方"可申请，后台可直接代为确认** |

# 九、数据导出与报表

## 9.1 后台导出

后台支持导出以下数据为Excel：经纪人列表、房源列表、成交记录列表、争议处理记录、门店维度统计报表。后台导出不受频率限制。导出操作记入audit_log。

## 9.2 定期报表

系统自动生成周报和月报。报表自动发送到管理员邮箱（后期实现）。

# 十、操作日志查看

后台提供audit_log的查询界面。支持按操作类型、操作人、时间范围、操作对象筛选。支持全文搜索。展示原始JSON详情。日志界面只有查看权限，无删除和编辑权限。
